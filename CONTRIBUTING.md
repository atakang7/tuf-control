# Contributing

Build and render the app using the [source build guide](docs/how-to/build.md). Pull requests should include the build result and a description of the hardware tested.

For new laptop support, follow [add a laptop model](docs/how-to/add-model.md). Changes to firmware write ranges need measurements from the physical machine.

Report unsafe hardware writes privately through the process in [SECURITY.md](SECURITY.md). Code adapted from other projects must be GPL-3.0-compatible and attributed in [third-party notices](THIRD-PARTY-NOTICES.md).
